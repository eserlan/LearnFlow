# LearnFlow Constitution

## Core principles
1. **Independent use:** A teenager must complete the primary journey without adult assistance; test with actual users, never assume.
2. **Respectful accessibility:** Age-appropriate language and visuals; no childish tone, forced gamification, or diagnostic assumptions.
3. **Faithfulness:** Preserve key facts, relationships, caveats and curriculum vocabulary; distinguish simplification from summarisation. Never invent source claims.
4. **Multimodal by default:** Audio-first, visual support, optional text, predictable playback and navigation.
5. **Privacy and safety:** Minimise collection, protect minors, avoid unnecessary accounts, default to private material, provide deletion and retention controls.
6. **Progressive complexity:** One obvious next action; advanced controls remain optional.
7. **Verifiable outcomes:** Each feature requires independently testable acceptance scenarios, accessibility checks and failure handling.

## Delivery gates
- Each spec follows Spec Kit: specify -> clarify -> plan -> tasks -> implement.
- Validate fidelity on representative Norwegian school material, including factual, mathematical and scientific notation.
- Test keyboard, screen reader, mobile touch, reduced motion, readable contrast, and recovery from interruptions.
- Do not treat generated explanations as authoritative; allow source comparison and uncertainty notices.
